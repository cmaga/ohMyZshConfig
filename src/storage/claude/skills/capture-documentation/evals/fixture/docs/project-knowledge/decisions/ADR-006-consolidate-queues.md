# ADR-006: Consolidate per-tenant queues

## Decision

Investigate consolidating per-tenant queues into the single queue from
[[ADR-001-use-postgres]].

## Context

Sections are deliberately out of order (Decision before Context) to
exercise SECTION_ORDER. Status "open" is a globally sanctioned status but
not one this bucket lists, exercising STATUS_UNEXPECTED; `superseded_by`
is set while status is not "superseded", exercising SUPERSEDED_BY_STRAY.

## Consequences

None yet; this is exploratory.
